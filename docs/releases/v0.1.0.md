The first release of bs, a fast Debug-mode compiler for Zig.

bs compiles Zig 0.17.1, and Zig 0.16.0 for a project whose `.bs.zon` says `.zig_version = "0.16"`, with each release's own std library, for x86_64 and aarch64 Linux and Apple Silicon macOS. It takes the same commands and flags as `zig build-exe`, `zig build-obj`, `zig run`, `zig test` and `zig build`, so a project's `build.zig` builds unchanged. Every build has Debug semantics. For ReleaseFast, use upstream `zig`.

- **Conformance:** bs passes every one of upstream's `test/behavior` tests that upstream passes on each target (2190 on x86_64-linux, 2077 on aarch64-linux, 2083 on aarch64-macos for 0.17; 2108 on x86_64-linux for 0.16), and all of std's tests.
- **Speed:** an edit to a project rebuilds only what the edit reaches, from an on-disk cache. Editing libvaxis's text_input example rebuilds in about 40 ms, where upstream Debug takes 1.1 s; editing upstream's own compiler takes about 0.4 s, where upstream takes 25 s.
- **Compile errors for agents:** exact locations, the facts needed to fix the error, and the fix when bs knows it, also as JSON.
- **C:** `-lc`, `@cImport`, and C and C++ sources through upstream's `zig cc`.
- **Lint:** a project with a `lint` section in `.bs.zon`, or a `.ziglint.zon`, gets ziglint 0.8.1's rules as compile errors in its own files.

bs needs upstream zig 0.17.1 on `PATH`, and zig 0.16.0 for a 0.16 project. See the README and CHANGELOG.md for details.
